Sunset Bay is an original 2D top-down open-world crime game built for make.fun's "Make GTA 6" bounty: explore a sun-soaked city on foot and by car, steal cars, outrun the police as your wanted level climbs, and run a four-mission story for Mara Vale — from a first car theft to a dockside getaway. Vanilla JavaScript, no libraries, no network: serve game/ and play.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
